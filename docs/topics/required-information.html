Required Information

This is the basic information required to make a Windows installer for transport.
FieldRequiredPurpose
Project source fileYesThe Delphi project/source file used to infer product name and default project paths.
Application EXEYesThe compiled program that will be copied into the installer payload.
Product nameYesThe display name used for folders, shortcuts, setup file naming, and reports.
PublisherRecommendedThe publisher shown in setup summaries and project metadata.
VersionYesThe product version written into the project and setup summary.
Install folderYesThe destination folder for the installed application.
Build output folderYesThe folder where the setup EXE, payload, reports, and export ZIP are written.
